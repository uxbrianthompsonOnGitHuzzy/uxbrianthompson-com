Challenge

Advisors start conversations with stale data.

Portfolio performance, asset allocation, and financial plan progress live in disconnected systems. Advisors pull reports manually before each meeting — often relying on data that’s days or weeks old. Planning conversations start with uncertainty instead of confidence.

Key Decisions

Design choices that defined the experience.

  • Real-time over cached: Live data connections ensure advisors never start a conversation with stale information
  • Visual + narrative: Charts paired with AI-generated plain-language summaries — advisors choose their modality
  • Drift as signal: Portfolio drift isn’t just displayed — it triggers contextual alerts in Agentic Advisor when thresholds are exceeded
  • Embedded in context: Performance data surfaces inside meeting prep, client records, and planning conversations — not a separate dashboard
  • Advisor-ready formatting: Outputs formatted for client-facing use — ready to share without reformatting
