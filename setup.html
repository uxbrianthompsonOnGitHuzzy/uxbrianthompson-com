FSC Agentic Wealth Experience

Universal Setup.

Self-service admin configuration — 3-step wizard, visual builder, under 30 minutes.

Challenge

Configuration was a bottleneck, not a feature.

Setup required a Professional Services engagement — weeks of lead time. Admins couldn't see the structure they were building until it was live. No way to reuse existing groups or insights across playbooks. Activation had no preflight — errors discovered post-deploy.

What We Built

A 3-step guided setup with visual builder.

Define, Configure, Activate. Admins see the structure they're building in real time — Groups, Insights, and Actions as spatial columns. Template path for speed, Custom path for control. Role-based playbooks from the same platform.

1. Define

Name & structure

Configuration name, description, columns. Create from scratch or start with a role-based template (Wealth Advisor, Paraplanner).

2. Configure

Visual builder

Groups, Insights, and Actions as spatial columns. Select existing or create new. Progressive validation with green checks.

3. Activate

One toggle

Preflight checks, one-toggle activation, immediate availability in Lightning App Builder. Error recovery built in.

The Experience

Key Decisions

Design choices that defined the experience.

  • Visual builder over forms: Spatial columns let admins see the structure they're building, not just fill out fields
  • Template + Custom paths: Start pre-populated for speed or blank for control — one wizard serves both needs
  • Progressive validation: Green checks confirm each column as it's configured — errors caught during build, not after deploy
  • Reuse over rebuild: "Select From Existing" for groups, insights, and actions — compose new playbooks from proven components
  • Preflight before setup: 9 prerequisite checks run automatically — permission sets, Data Cloud, Einstein all verified
